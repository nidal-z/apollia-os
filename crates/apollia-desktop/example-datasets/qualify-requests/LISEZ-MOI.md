# Jeu de démonstration : qualifier des demandes

Ce dossier accompagne l'exemple « Qualifier des demandes ». Tout y est inventé
pour l'essai : la fondation, son fonds d'aide, les associations et leurs
demandes n'existent pas. Aucune donnée personnelle n'y figure. Seuls les noms
de communes sont réels, parce que l'agent vérifie leur population sur une
source publique.

## Ce qu'il contient

- `demandes.xlsx` : un classeur de douze demandes d'aide, une par ligne.
- `referentiel/` : trois documents de référence, que l'agent consulte pour
  qualifier chaque demande.

## Comment l'essayer

1. Sur la fiche de l'agent, cochez le dossier `referentiel` parmi ses sources.
2. Lancez un lot sur `demandes.xlsx`.
3. Le lot rend un tableau : une ligne par demande, avec sa qualification, son
   motif et ses sources.

Vous pouvez supprimer ce dossier quand vous le voulez : l'application n'y
revient pas.
