# Tutorials

Learning-oriented lessons that take you end to end. They are written for
people who build packages, with the command line and a code editor.

To use Apollia without writing code, the lessons are not the way in: install
the application with [Install Apollia Desktop](/how-to/install-the-desktop-app),
whose first launch ends on a first agent at work, then follow the
[help center](/operator-help).

## Lessons

- [Your first agent](/tutorials/your-first-agent): declare an agent in
  `apollia.toml`, write one Python tool, then build, install and run the
  package.
- [Build a multi-agent assistant](/tutorials/build-a-multi-agent-assistant):
  compose two agents, a Python tool and a workflow that chains them into one
  package.
- [Drive Apollia from your product](/tutorials/drive-apollia-from-your-product):
  embed the runtime and control a run from a host application over the HTTP API.

If you have not built the runtime yet, start with
[Install and run the runtime](/how-to/install-and-run).
