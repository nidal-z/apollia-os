# Getting acquainted

> The few steps Apollia opens with the first time.

## What it is for

The first time, Apollia walks you through a few steps: the language, the model that will answer, a first agent, a connection and a first task. Only the model step is required.

## What you can do

- Choose a model for this machine, or a server you already use.
- Skip an optional step and come back to it later.
- Open the guide at any step with the help icon of the top bar.
