# The Automations screen

> Rules that start your agents without you.

## What it is for

An automation starts an agent or a workflow on its own: on a schedule, when a file changes, or when a call comes in from another tool.

## What you can do

- Create an automation by saying when it must run.
- Choose the agent or the workflow it starts.
- See the automations in place and what each one starts.
