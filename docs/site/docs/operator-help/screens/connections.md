# The Connections screen

> What links your agents to your own services and files.

## What it is for

A connection gives agents tools to work with a service of yours: a Google Workspace or Microsoft 365 account, a mailbox, a folder of your computer, or a service from the catalogue. The tools that ship with Apollia are listed here too.

## What you can do

- Add a connection from the selection of Apollia or from the public catalogue, or add a custom one.
- Connect an account and test the connection.
- Turn the built-in tools on or off: web search, page reading, code execution.
