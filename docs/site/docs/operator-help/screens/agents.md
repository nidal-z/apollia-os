# The Agents screen

> Your agents and your workflows, in one list.

## What it is for

Agents work for you: each has a mission, a model and accesses you decide. Workflows chain several steps. This screen lists both and is where a new one starts.

## What you can do

- Create an agent by describing what you want: Apollia writes its sheet, and nothing is saved before you validate it.
- Start from an example offered by Apollia, or install a package.
- Open the sheet of an agent to read what it does and what it may access.
