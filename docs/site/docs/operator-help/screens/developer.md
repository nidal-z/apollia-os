# The Developer screen

> The entry of those who plug their own programs into Apollia.

## What it is for

The Developer screen is meant for people who connect their own programs to Apollia. It is listed in the sidebar only while the developer mode is on. Day to day, nothing here is needed to work with agents. It has two views: **Local server** and **Documentation**.

## What you can do

- Start or stop the local server, which answers the programs of this computer, and copy the address it is reachable at.
- Load a model into the server with **Load a model**, and read the calls it receives in **Server logs**.
- Open **Server settings** to change the port, require authentication and create the tokens a program uses with **Manage tokens**.
- Read the developer documentation in the **Documentation** view.
- Turn the developer mode on or off in **Settings**, section **Developer**, where Apollia is also exposed as an MCP server.
- Reach the technical screens the mode adds to the sidebar, under **Developer mode**: **Transcriptions**, **Observability** and **Memory**.
