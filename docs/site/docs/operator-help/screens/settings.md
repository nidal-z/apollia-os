# The Settings window

> The preferences of the application, in a window above the current screen.

## What it is for

Settings open in a window above the screen you were on, which stays where it was. Its sections are **General** (the language and the updates), **Appearance**, **Profile**, **Chat**, **Dictation**, **Model defaults**, **Integrations**, **Notifications** and **Developer**, then, under **System**, **Engines** and **Hardware**.

## What you can do

- Change the language or the theme of the interface.
- Fill in your profile, which an agent reads only when its sheet lists it as a source.
- Turn the developer mode on, in the **Developer** section.
