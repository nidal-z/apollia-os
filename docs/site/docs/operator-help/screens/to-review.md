# The To review screen

> Everything that waits for your answer, in one list.

## What it is for

Agreements asked by agents, questions, paused tasks and batch items are gathered here, with the same answers as in the Chat. Answering here resumes the conversation, the task or the batch concerned.

## What you can do

- Grant or refuse an agreement an agent asks for.
- Answer a question an agent asks you.
- Resume a paused task or a batch item.
