# The Memory screen

> Everything the agents remembered, in one place.

## What it is for

The Memory screen shows the whole of what the agents remembered. It is listed in the sidebar only while the developer mode is on. Without it, the memory of an agent is read on its sheet, and your profile in Settings.

## What you can do

- Search what was remembered.
- Open an entry to read its detail.
- Delete an entry.
