# The history of the batches

> Every batch, most recent first, whatever the agent.

## What it is for

A batch is one task handed to an agent for a series of items. This screen, reached from the Agents screen, keeps every batch that was run.

## What you can do

- Open a batch to read it again.
- Export what a batch produced.
- Run the failures of a batch again.
