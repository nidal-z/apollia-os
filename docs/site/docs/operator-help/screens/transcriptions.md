# The Transcriptions screen

> The history of your voice dictations.

## What it is for

The Transcriptions screen keeps what you dictated and what was transcribed from a file. It is listed in the sidebar only while the developer mode is on.

## What you can do

- Read a past dictation again.
- Transcribe an audio file.
- Delete a transcription.
