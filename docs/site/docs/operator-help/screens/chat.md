# The Chat screen

> Where you talk with Apollia, with one of your agents, or directly with a model.

## What it is for

The Chat is where work gets asked for and followed. A conversation is held with Apollia, with an agent you choose, or with a model alone, and it stays on this machine.

## What you can do

- Choose the agent or the model that answers, from the selector of the top bar.
- Follow what an agent does while it works, step by step, in the Steps panel.
- Answer an agreement an agent asks for, right in the conversation.
