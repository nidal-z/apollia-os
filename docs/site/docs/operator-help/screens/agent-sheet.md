# The sheet of an agent

> Everything one agent is and does, on one page of the Agents screen.

## What it is for

The sheet says what the agent does (its mission and examples of requests), which model answers for it, what it may do by family of action, which sources it consults, and what it did. Its tabs separate the sheet itself, the activity and the memory.

Two sources change what the agent keeps. With **The agent's memory** checked, the agent keeps notes of its own and finds them again across its conversations. With **Profile** checked, the agent reads your profile and may propose a fact for it, which you accept or refuse each time.

## What you can do

- Adjust the agent: its mission, its model, its accesses and its sources.
- Open a past run to read its input, its output and its steps.
- Read what the agent remembered, search it and erase it.
