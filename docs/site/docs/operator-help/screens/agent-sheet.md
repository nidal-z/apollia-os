# The sheet of an agent

> Everything one agent is and does, on one page of the Agents screen.

## What it is for

The sheet says what the agent does (its mission and examples of requests), which model answers for it, what it may do by family of action, which sources it consults, and what it did.

## What you can do

- Adjust the agent: its mission, its model, its accesses.
- Open a past run to read its input, its output and its steps.
- Read what the agent remembered, search it and erase it.
