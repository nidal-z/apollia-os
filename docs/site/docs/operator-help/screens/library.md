# The Library screen

> What you installed, with where it comes from.

## What it is for

The Library lists what was installed on this machine: agents, workflows, tools and connections, each with its publisher and its signature. A package brings several of them at once, in a single file.

## What you can do

- Install a package.
- Read who published an item and whether its signature holds.
- See what a package brought with it.
