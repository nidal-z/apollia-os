## What running locally means here

Apollia keeps inference, transcription, memory and audit on the machine. The
desktop app embeds its own LLM engine and its own speech-to-text engine, so a
fresh launch contacts nobody, and nothing about a conversation leaves the
machine unless an explicit action sends it.

- [Sovereignty and local-first](/explanation/sovereignty-and-local-first) states the guarantee and its boundaries.
- [The eight principles](/explanation/the-8-principles) is the shortest path to the design.
- [Audit and verify](/how-to/audit-and-verify) shows how to check what actually happened.

## Source of truth

The three machine references are never hand-copied. They are generated from the
code:

- the HTTP API reference from the delivered OpenAPI spec,
- the CLI reference from the `apollia-os` command tree,
- the SDK contract from the typed `Ctx` services.

Run `bash regen.sh` to refresh them.
