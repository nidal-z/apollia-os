# Architecture

The public system cartography, following arc42 and the C4 model. Derived from
the capability registry, it never redefines a fact that lives in the reference
sections; it links to them.

## Target structure (to build fresh)

The arc42 skeleton is written in a later phase, recast from the capability
registry. Planned sections:

- Introduction and goals.
- Constraints.
- Context and scope (C4 system context).
- Solution strategy.
- Building block view (C4 containers and components), from the building-block pages.
- Runtime view (the actor model and state machines).
- Deployment view.
- Cross-cutting concepts.
- Architecture decisions (bare ADR identifiers, links activated post-launch).
- Quality requirements.
- Risks and technical debt.
- Glossary.

_This is a phase 1 placeholder. The arc42 skeleton is out of scope for the
infra phase._
