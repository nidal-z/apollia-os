# L'écran Journal

> Chaque action des agents et chaque changement d'accès, en clair.

## À quoi ça sert

Le Journal liste ce que les agents ont fait et ce qui a changé dans leurs accès, du plus récent au plus ancien. Il reste sur cet appareil.

## Ce que vous pouvez faire

- Filtrer les entrées pour retrouver une action ou un changement.
- Ouvrir une entrée pour lire son détail dans le panneau de détail.
- Exporter les entrées qui correspondent aux filtres en cours.
