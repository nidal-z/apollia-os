# L'écran Connexions

> Ce qui relie vos agents à vos services et à vos fichiers.

## À quoi ça sert

Une connexion donne aux agents des outils pour travailler avec l'un de vos services : un compte Google Workspace ou Microsoft 365, une boîte mail, un dossier de votre ordinateur, ou un service du catalogue. Les outils fournis avec Apollia figurent ici aussi.

## Ce que vous pouvez faire

- Ajouter une connexion depuis la sélection d'Apollia ou le catalogue public, ou en ajouter une personnalisée.
- Connecter un compte et tester la connexion.
- Activer ou désactiver les outils intégrés : recherche web, lecture de page, exécution de code.
