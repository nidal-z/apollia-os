# L'écran Autorisations

> Ce que chaque agent a le droit de faire sur ce poste.

## À quoi ça sert

L'écran Autorisations montre, agent par agent, ce que vous avez accordé une fois pour toutes. Un accord se retire en un clic, et chaque retrait est inscrit au Journal.

## Ce que vous pouvez faire

- Lire ce qu'un agent peut faire sans vous demander.
- Retirer un accord que vous aviez donné pour de bon.
- Vérifier au Journal que le retrait a été inscrit.
