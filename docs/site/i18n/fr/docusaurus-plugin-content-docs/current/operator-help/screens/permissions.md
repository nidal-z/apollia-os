# L'écran Autorisations

> Ce que chaque agent a le droit de faire sur ce poste.

## À quoi ça sert

L'écran Autorisations montre, agent par agent et sous **Pour tous les agents**, ce que vous avez accordé une fois pour toutes : les accès accordés par famille, les **« Toujours » donnés** et les **Règles fines**. Un accord se retire en un clic, et chaque retrait est inscrit au Journal. Le panneau **Politique de l'organisation** dit si une politique de votre organisation s'applique.

## Ce que vous pouvez faire

- Lire ce qu'un agent peut faire sans vous demander.
- Retirer un accord que vous aviez donné pour de bon avec **Retirer**, ou plusieurs d'un coup avec **Tout révoquer**.
- Ouvrir la politique de votre organisation avec **Voir la politique**.
- Vérifier au Journal que le retrait a été inscrit.
