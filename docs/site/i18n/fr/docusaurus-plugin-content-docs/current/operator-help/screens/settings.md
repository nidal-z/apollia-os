# La fenêtre Réglages

> Les préférences de l'application, dans une fenêtre au-dessus de l'écran courant.

## À quoi ça sert

Les Réglages s'ouvrent dans une fenêtre au-dessus de l'écran où vous étiez, qui reste en place. Ses sections couvrent la langue et les mises à jour, l'apparence, votre profil, le chat, les notifications et les valeurs par défaut des modèles.

## Ce que vous pouvez faire

- Changer la langue ou le thème de l'interface.
- Renseigner votre profil, qu'un agent ne lit que si sa fiche le compte parmi ses sources.
- Allumer le mode développeur, dans la section Développeur.
