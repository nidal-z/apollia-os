# La fenêtre Réglages

> Les préférences de l'application, dans une fenêtre au-dessus de l'écran courant.

## À quoi ça sert

Les Réglages s'ouvrent dans une fenêtre au-dessus de l'écran où vous étiez, qui reste en place. Ses sections sont **Général** (la langue et les mises à jour), **Apparence**, **Profil**, **Chat**, **Dictée**, **Défauts des modèles**, **Intégrations**, **Notifications** et **Développeur**, puis, sous **Système**, **Moteurs** et **Matériel**.

## Ce que vous pouvez faire

- Changer la langue ou le thème de l'interface.
- Renseigner votre profil, qu'un agent ne lit que si sa fiche le compte parmi ses sources.
- Allumer le mode développeur, dans la section **Développeur**.
