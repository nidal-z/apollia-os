# Faire connaissance

> Les quelques étapes par lesquelles Apollia commence la première fois.

## À quoi ça sert

La première fois, Apollia vous fait passer par quelques étapes : la langue, le modèle qui répondra, le modèle qui cherche dans vos documents par le sens, quelques mots sur vous, un premier agent, une connexion et une première tâche. Seule l'étape du modèle est obligatoire.

## Ce que vous pouvez faire

- Choisir un modèle pour ce poste, ou un serveur que vous utilisez déjà.
- Passer une étape facultative et y revenir plus tard.
- Ouvrir le guide à n'importe quelle étape avec l'icône d'aide de la barre du haut.
