# La vue d'un lot

> Un lot, élément par élément.

## À quoi ça sert

La vue d'un lot montre chacun de ses éléments avec son état. Un élément ouvert montre son détail dans le panneau de détail, à côté de la liste.

## Ce que vous pouvez faire

- Ouvrir un élément pour lire son détail.
- Exporter le lot.
- Relancer ses échecs.
