# L'écran Mémoire

> Tout ce que les agents ont retenu, au même endroit.

## À quoi ça sert

L'écran Mémoire montre l'ensemble de ce que les agents ont retenu. Il n'apparaît dans la barre latérale que lorsque le mode développeur est allumé. Sans lui, la mémoire d'un agent se lit sur sa fiche, et votre profil dans Réglages.

## Ce que vous pouvez faire

- Chercher dans ce qui a été retenu.
- Ouvrir une entrée pour lire son détail.
- Supprimer une entrée.
