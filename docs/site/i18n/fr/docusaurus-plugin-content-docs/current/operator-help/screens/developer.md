# L'écran Développeur

> L'entrée de ceux qui branchent leurs propres programmes sur Apollia.

## À quoi ça sert

L'écran Développeur s'adresse à ceux qui relient leurs propres programmes à Apollia. Il n'apparaît dans la barre latérale que lorsque le mode développeur est allumé. Au quotidien, rien ici n'est nécessaire pour travailler avec des agents. Il a deux vues : **Serveur local** et **Documentation**.

## Ce que vous pouvez faire

- Démarrer ou arrêter le serveur local, qui répond aux programmes de cet ordinateur, et copier l'adresse où il est joignable.
- Charger un modèle dans le serveur avec **Charger un modèle**, et lire les appels qu'il reçoit dans **Journaux du serveur**.
- Ouvrir **Réglages du serveur** pour changer le port, exiger l'authentification et créer les jetons qu'un programme emploie avec **Gérer les jetons**.
- Lire la documentation développeur dans la vue **Documentation**.
- Allumer ou éteindre le mode développeur dans **Réglages**, section **Développeur**, où Apollia s'expose aussi comme serveur MCP.
- Atteindre les écrans techniques que le mode ajoute à la barre latérale, sous **Mode développeur** : **Transcriptions**, **Observabilité** et **Mémoire**.
