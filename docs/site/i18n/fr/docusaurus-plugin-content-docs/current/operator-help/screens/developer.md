# L'écran Développeur

> L'entrée de ceux qui branchent leurs propres programmes sur Apollia.

## À quoi ça sert

L'écran Développeur s'adresse à ceux qui relient leurs propres programmes à Apollia. Il n'apparaît dans la barre latérale que lorsque le mode développeur est allumé. Au quotidien, rien ici n'est nécessaire pour travailler avec des agents.

## Ce que vous pouvez faire

- Allumer ou éteindre le mode développeur dans Réglages, section Développeur.
- Atteindre les écrans techniques que le mode ajoute à la barre latérale : Transcriptions, Observabilité et Mémoire.
