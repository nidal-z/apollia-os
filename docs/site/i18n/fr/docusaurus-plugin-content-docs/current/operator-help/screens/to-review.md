# L'écran À valider

> Tout ce qui attend votre réponse, dans une seule liste.

## À quoi ça sert

Les accords demandés par les agents, les questions, les tâches en pause et les éléments de lot sont réunis ici, avec les mêmes réponses que dans le Chat. Répondre ici reprend la conversation, la tâche ou le lot concerné.

## Ce que vous pouvez faire

- Restreindre la liste avec **Tout**, **Décisions**, **Questions** ou **Éléments de lot**.
- Accorder ou refuser un accord qu'un agent demande.
- Répondre à une question qu'un agent vous pose avec **Répondre**, ou décliner avec **Refuser de répondre**.
- Reprendre une tâche en pause ou un élément de lot.
