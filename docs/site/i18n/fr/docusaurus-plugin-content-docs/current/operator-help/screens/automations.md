# L'écran Automatisations

> Des règles qui lancent vos agents sans vous.

## À quoi ça sert

Une automatisation lance un agent ou un workflow toute seule : selon une planification, quand un fichier change, ou quand un appel arrive d'un autre outil.

## Ce que vous pouvez faire

- Créer une automatisation en disant quand elle doit se lancer.
- Choisir l'agent ou le workflow qu'elle lance.
- Voir les automatisations en place et ce que chacune lance.
