# L'écran Chat

> L'endroit où vous parlez avec Apollia, avec l'un de vos agents, ou directement avec un modèle.

## À quoi ça sert

Le Chat est l'endroit où le travail se demande et se suit. Une conversation se tient avec Apollia, avec un agent que vous choisissez, ou avec un modèle seul, et elle reste sur ce poste.

## Ce que vous pouvez faire

- Choisir l'agent ou le modèle qui répond, depuis le sélecteur de la barre du haut.
- Suivre ce que fait un agent pendant qu'il travaille, étape par étape, dans le panneau Étapes.
- Répondre à un accord qu'un agent demande, directement dans la conversation.
