# L'historique des lots

> Tous les lots, du plus récent au plus ancien, quel que soit l'agent.

## À quoi ça sert

Un lot est une même tâche confiée à un agent pour une série d'éléments : les lignes d'un fichier Excel ou CSV, les fichiers d'un dossier, ou les messages d'une boîte mail. Cet écran, atteint par **Historique des lots** en haut de l'écran Agents, garde tous les lots qui ont été lancés, avec leur agent, leur source, leur issue et le nombre de leurs éléments traités.

## Ce que vous pouvez faire

- Chercher un lot par son fichier ou son agent, et filtrer la liste par agent ou par issue.
- Ouvrir un lot pour le relire : sa vue montre ce que vous avez demandé, les fichiers qu'il a produits et ses résultats.
- Exporter ce qu'un lot a produit.
- Relancer les échecs d'un lot.
