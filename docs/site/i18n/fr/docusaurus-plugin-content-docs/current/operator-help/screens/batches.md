# L'historique des lots

> Tous les lots, du plus récent au plus ancien, quel que soit l'agent.

## À quoi ça sert

Un lot est une même tâche confiée à un agent pour une série d'éléments. Cet écran, atteint depuis l'écran Agents, garde tous les lots qui ont été lancés.

## Ce que vous pouvez faire

- Ouvrir un lot pour le relire.
- Exporter ce qu'un lot a produit.
- Relancer les échecs d'un lot.
