# L'écran Observabilité

> La vue technique de ce qui a tourné.

## À quoi ça sert

L'écran Observabilité réunit la chronologie des exécutions, le coût des modèles et les messages que les agents échangent, avec des onglets pour la délégation, le cache de plans, les hooks et la politique de capture. Il n'apparaît dans la barre latérale que lorsque le mode développeur est allumé. Le Journal raconte la même chose en clair.

## Ce que vous pouvez faire

- Suivre une exécution dans la chronologie.
- Surveiller ce que coûtent les modèles.
- Lire les messages échangés par les agents, dans l'onglet Messagerie.
