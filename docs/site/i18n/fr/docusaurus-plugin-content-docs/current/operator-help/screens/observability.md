# L'écran Observabilité

> La vue technique de ce qui a tourné.

## À quoi ça sert

L'écran Observabilité réunit la chronologie des exécutions, le coût des modèles et la piste des appels d'outils. Il n'apparaît dans la barre latérale que lorsque le mode développeur est allumé. Le Journal raconte la même chose en clair.

## Ce que vous pouvez faire

- Suivre une exécution dans la chronologie.
- Surveiller ce que coûtent les modèles.
- Lire la piste des appels d'outils.
