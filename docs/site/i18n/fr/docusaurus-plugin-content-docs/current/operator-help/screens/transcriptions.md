# L'écran Transcriptions

> L'historique de vos dictées vocales.

## À quoi ça sert

L'écran Transcriptions garde ce que vous avez dicté et ce qui a été transcrit depuis un fichier. Il n'apparaît dans la barre latérale que lorsque le mode développeur est allumé.

## Ce que vous pouvez faire

- Relire une dictée passée.
- Transcrire un fichier audio.
- Supprimer une transcription.
