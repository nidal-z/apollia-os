# L'écran IA

> Les modèles qui répondent : ceux de ce poste et ceux de vos serveurs.

## À quoi ça sert

L'écran IA montre les modèles chargés en mémoire, les modèles installés sur ce poste, et les serveurs qui mettent à disposition les modèles de votre organisation sans les installer ici.

## Ce que vous pouvez faire

- Découvrir un modèle adapté à ce poste, ou importer un fichier de modèle que vous avez déjà.
- Libérer la mémoire qu'occupe un modèle chargé.
- Ajouter le serveur d'IA de votre organisation et le tester.
