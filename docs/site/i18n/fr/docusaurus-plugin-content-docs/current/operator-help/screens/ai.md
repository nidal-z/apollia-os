# L'écran IA

> Les modèles qui répondent : ceux de ce poste et ceux de vos serveurs.

## À quoi ça sert

L'écran IA montre les modèles chargés en mémoire (**Chargés**), les modèles installés sur ce poste (**Sur ce poste**), et, sous **Serveurs**, les serveurs qui mettent à disposition les modèles de votre organisation sans les installer ici.

## Ce que vous pouvez faire

- Trouver un modèle adapté à ce poste avec **Découvrir des modèles**, ou apporter un fichier de modèle que vous avez déjà avec **Importer un fichier**.
- Libérer la mémoire qu'occupe un modèle chargé avec **Décharger**, ou le garder chargé avec **Garder en mémoire**.
- Ajouter le serveur d'IA de votre organisation avec **Ajouter un serveur**, puis vérifier qu'il répond avec **Tester**.
