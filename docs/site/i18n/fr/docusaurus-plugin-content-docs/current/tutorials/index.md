# Tutoriels

Des leçons orientées apprentissage qui vous font aller de bout en bout. Elles
s'adressent à qui construit des paquets, avec la ligne de commande et un
éditeur de code.

Pour utiliser Apollia sans écrire de code, ces leçons ne sont pas la porte
d'entrée : installez l'application avec
[Installer Apollia Desktop](/how-to/install-the-desktop-app), dont le premier
lancement se termine sur un premier agent au travail, puis suivez le
[centre d'aide](/operator-help).

## Leçons

- [Votre premier agent](/tutorials/your-first-agent) : déclarez un agent dans
  `apollia.toml`, écrivez un outil Python, puis construisez, installez et
  exécutez le paquet.
- [Construire un assistant multi-agents](/tutorials/build-a-multi-agent-assistant) :
  composez deux agents, un outil Python et un workflow qui les enchaîne en un
  seul paquet.
- [Piloter Apollia depuis votre produit](/tutorials/drive-apollia-from-your-product) :
  embarquez le runtime et pilotez une exécution depuis une application hôte via
  l'API HTTP.

Si vous n'avez pas encore construit le runtime, commencez par
[Installer et lancer le runtime](/how-to/install-and-run).
