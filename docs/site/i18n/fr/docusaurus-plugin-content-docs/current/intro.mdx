## Ce que veut dire « tout en local » ici

Apollia garde l'inference, la transcription, la memoire et l'audit sur la
machine. L'application de bureau embarque son propre moteur LLM et son propre
moteur de reconnaissance vocale : un lancement a froid ne contacte personne, et
rien d'une conversation ne quitte la machine sans une action explicite.

- [Souverainete et local-first](/explanation/sovereignty-and-local-first) enonce la garantie et ses limites.
- [Les huit principes](/explanation/the-8-principles) est le chemin le plus court vers la conception.
- [Auditer et verifier](/how-to/audit-and-verify) montre comment controler ce qui s'est vraiment passe.

## Source de verite

Les trois references machine ne sont jamais recopiees a la main. Elles sont
generees depuis le code :

- la reference de l'API HTTP depuis la specification OpenAPI livree,
- la reference CLI depuis l'arbre de commandes `apollia-os`,
- le contrat SDK depuis les services types de `Ctx`.

Lancez `bash regen.sh` pour les rafraichir.
