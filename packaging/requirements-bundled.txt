# Apollia OS - "batteries included" Python site-packages bundled into the
# desktop DMG/AppImage.
#
# These packages are pre-installed in the bundled Python distribution so that
# workers (excel, csv, pdf, ...) can import them without any runtime pip
# install.
#
# This file is a hash-locked set: every package, transitive dependencies
# included, is pinned with `==` and carries the sha256 of every wheel a
# supported platform can select (macOS arm64 and x86_64, Linux glibc x86_64
# and aarch64, Windows x86_64). build-python-bundle.sh installs it with
# `--require-hashes`, so a wheel that does not match a pinned sum is refused.
# Windows aarch64 is not covered: pandas publishes no wheel for it.
#
# To change a pin: edit the version, then for each supported platform run
#   pip download <name>==<version> --only-binary=:all: --no-deps \
#       --platform <plat> --python-version 3.13 --implementation cp -d <dir>
# with <plat> in macosx_11_0_arm64, macosx_10_13_x86_64,
# manylinux_2_17_x86_64, manylinux_2_17_aarch64, win_amd64, and pin the
# sha256 of every downloaded wheel. scripts/check_download_sums.py refuses a
# line without a sum.
#
# Versioning policy for v0.1.0: pin exact versions to get reproducible builds
# across CI and local dev. Upgrade on a schedule, not ad-hoc, and never onto a
# version pip-audit flags: the Dependency Check CI job audits this exact file.
