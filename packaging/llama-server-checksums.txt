# SHA256 checksums for the pinned llama.cpp release assets bundled as the local
# LLM engine. One line per asset: "<sha256>  <asset-filename>".
#
# Provenance: every hash below was computed locally with `shasum -a 256` on the
# downloaded asset, then cross-checked against the digest GitHub reports for the
# same asset. All matched. The local hash is what is pinned here, so a
# later download is verified against bytes that were hashed here rather than
# against a value the serving side could simply restate.
#
# To bump the pin: change LLAMA_CPP_TAG in fetch-llama-server.sh, then for each
# asset run `curl -fsSL <asset-url> -o <asset> && shasum -a 256 <asset>` and
# replace the lines below. Never leave a line out: fetch-llama-server.sh refuses
# to stage an asset it cannot verify, which is what keeps an unverified binary
# out of a release bundle.
#
