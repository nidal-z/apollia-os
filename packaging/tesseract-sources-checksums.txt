# SHA256 checksums of the C++ sources the build script of `tesseract-rs`
# compiles, read by packaging/fetch-tesseract-sources.sh.
#
# The first non-comment line names the `tesseract-rs` version these archives
# serve: its build script hardcodes both URLs, so a bump of the crate in
# Cargo.toml means new URLs and new lines here. Then one line per archive:
#   <sha256>  <url>  <commit>
# The URL is exactly the one the build script downloads. The commit is the one
# GitHub writes in the comment of a tag archive (`unzip -z`); it ties the
# archive to the upstream tag, read with
#   gh api repos/<owner>/<project>/git/ref/tags/<tag>
# (for an annotated tag, follow the tag object with `git/tags/<sha>`).
#
# Provenance: every sum below was computed locally with `shasum -a 256` on the
# downloaded archive, and every commit read from the archive and compared with
# the upstream tag. GitHub does not promise tag archives byte for byte: if one
# is ever regenerated, the script fails, it never accepts it.
#
# To bump: for each URL, `curl -fsSL <url> -o <file> && shasum -a 256 <file>`
# and `unzip -z <file>`, compare the commit with the tag, replace the line.
