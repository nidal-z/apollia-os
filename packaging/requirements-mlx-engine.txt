# Apollia OS - the MLX inference engine (vllm-mlx) and the part of its
# dependency closure that serving a model imports, installed into the macOS
# Apple Silicon bundle only.
#
# This set is NOT the agents' site-packages (requirements-bundled.txt). It is
# installed by build-mlx-engine.sh into its own directory,
# python/engines/mlx/site-packages, which the agents' interpreter never puts on
# sys.path. The engine is started with the bundled interpreter in `-S` mode
# and that directory as its only package path, so the two sets never mix.
#
# Hash-locked: every package is pinned with `==` and carries the sha256 of the
# one wheel the macOS arm64 selection below picks. build-mlx-engine.sh
# installs it with `--require-hashes`, and scripts/check_download_sums.py
# refuses a line without a sum.
#
# Pruned, not resolved: the file is installed with `--no-deps`, and it lists
# only what `vllm_mlx.cli serve` imports to serve a model over the OpenAI
# API (chat, streaming, tool calls, JSON schema output). The rest of the
# declared closure of vllm-mlx is left out on purpose:
#   - mlx-embeddings, GPL-3.0: never shipped. vllm-mlx imports it only for the
#     embeddings endpoint, which the bundle therefore does not serve.
#     scripts/check_download_sums.py refuses a line that names it, and
#     build-mlx-engine.sh fails if it is installed.
#   - torch, torchvision, scipy, sympy, mpmath, networkx: transformers probes
#     for them when present, and serving needs none of them.
#   - gradio and its stack, opencv-python, pandas, mlx-audio and the audio
#     packages, mcp, prometheus-client and tabulate: the web UI, video input,
#     audio, the engine's own MCP client, metrics and the benchmark, none of
#     which the daemon uses; and the helpers no served request loads
#     (hf-xet, fsspec, typer, httpx2, cryptography among them).
# Adding a package back is a decision: check its license, pin it here with
# its sum, and replay the serving check below.
#
# The wheels are selected for macosx_14_0_arm64, never for the build host:
# mlx and mlx-metal publish one wheel per macOS major, and a wheel picked on a
# newer runner would not load on an older machine. macOS 14 is the floor of
# mlx at this pin, so the engine needs macOS 14 or later.
#
# To change a pin: edit the version of vllm-mlx, then resolve and download the
# closure with the bundled interpreter,
#   python3.13 -m pip download vllm-mlx==<version> --only-binary=:all: \
#       --platform macosx_14_0_arm64 --python-version 3.13 \
#       --implementation cp --abi cp313 -d <dir>
# pin the packages a served model imports with their sha256, and check the
# license of each new one before pinning it. A served model is the check:
#   PYTHONPATH=<site-packages> python3.13 -S -m vllm_mlx.cli serve <model> \
#       --host 127.0.0.1 --port <port>
# then one chat completion, one streamed, one with tools and one with a JSON
# schema response format.
