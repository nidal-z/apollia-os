# SHA256 checksums for the pinned python-build-standalone archives bundled as
# the embedded Python runtime. One line per archive:
# "<sha256>  <archive-filename>". Same format as llama-server-checksums.txt.
#
# Provenance: every hash below was computed locally with `shasum -a 256` on the
# downloaded archive, then cross-checked against the digest GitHub reports for
# the same release asset. All six matched. The local hash is what is pinned
# here, so a later download is verified against bytes that were hashed here
# rather than against a value the serving side could simply restate.
#
# To bump the pin: change PBS_TAG / CPYTHON_VERSION in
# fetch-python-standalone.sh, then for each archive run
# `curl -fsSL <archive-url> -o <archive> && shasum -a 256 <archive>` and
# replace the lines below. Never leave a line out: fetch-python-standalone.sh
# refuses to extract an archive it cannot verify, and
# scripts/check_download_sums.py refuses a triple without a pinned sum.
