# Apollia OS Roadmap

This document captures the direction of Apollia OS at a level higher than the
changelog. It is a living document: items move, get reordered, and sometimes
drop entirely. Concrete delivery is tracked in issues and milestones; this
page is the intent.

## v0.1.0 (released 2026-06-03), initial public preview

The first public release. Single-maintainer preview.

- Local-first Rust runtime for autonomous AI agents.
- Native PyO3 bridge for Python agents (no subprocess).
- Full Model Context Protocol (MCP) support: 18-entry catalog, stdio and HTTP
  transports, custom server installation via the desktop UI.
- LLM router with a local quantized backend (the embedded llama-server, upstream
  llama.cpp) plus optional Anthropic and OpenAI providers.
- ORIA orchestration engine for multi-step plans with replanning.
- Desktop app (Tauri 2) and CLI (`apollia-os`) sharing the same runtime.
- 40+ CLI subcommands at parity with the Desktop.
- Built-in agents: onboarding guide, Apollia coach.
- Workspace tooling: sandboxed bash, file IO, web search, web read, HTTP fetch.
- Audit trail, HITL approvals, permission rules with scope (session, project,
  agent).

## v0.1.1, polish (target: late June 2026)

Stabilization based on early feedback and on-the-floor friction.

- CLI completeness: surface `mcp catalogue` and enrichments through CLI (today
  desktop-only).
- CLI `chat-config authorizations` runtime route.
- Cross-OS CI: `cli-e2e.sh` validated on Linux x86_64 and Windows artifacts.
- Bug-fixing and small UX iterations after onboarding sessions.
- Cleanup pass on the documentation corpus.

## v0.2, themes under consideration

The exact mix depends on what is observed in v0.1.x. Items below are themes,
not commitments.

- **Vision support**: a `vision-worker` once a local vision-capable LLM
  backend is stable.
- **Agent marketplace foundations**: signed manifests, dependency resolution,
  install paths for community agents.
- **Plan caching and replay**: improved persistence and inspection of plans
  generated by ORIA.
- **Observability**: richer dashboards, OpenTelemetry export, plan-level
  metrics.
- **Multi-user mode** for small team deployments, behind a feature flag.

## v1.0, long-term

A stable runtime suitable for unattended deployments and external dependency.

- API stability commitment: semver applies to the Rust crate APIs and the
  Python SDK contract.
- LTS branch with a clear backport policy.
- Production-grade docs, examples, and tutorials.
- Performance and footprint targets for embedded use.
- Reviewed security model with documented threat model and mitigations.

## How priorities move

Apollia OS is single-maintainer. Priorities respond to:

- Real usage friction reported through issues.
- The maintainer's professional services pipeline (a steady source of
  real-world agent requirements).
- Upstream changes in the Rust async ecosystem, Tauri, and MCP specifications.

The roadmap is not a backlog. Concrete tasks live in the issue tracker.
