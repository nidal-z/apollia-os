# Invitation et Suivi — Réunion Hebdomadaire d'Équipe

## 1. Création de l'Invitation Récurrente

### Sur Google Calendar / Outlook

**Titre :** 🔄 Réunion Hebdo d'Équipe — [Nom de l'équipe]

**Description :**
```
Réunion hebdomadaire de l'équipe [Nom].

📍 Lieu : [Salle de réunion / Lien visio]
⏰ Durée : 60 minutes
📋 Ordre du jour : envoyé 24h avant par l'animateur

Objectifs :
- Faire le point sur l'avancement des projets
- Identifier les blocages
- Partager les informations importantes
- Renforcer la cohésion d'équipe

Règles :
- Ponctualité requise
- Ordre du jour partagé avant la réunion
- Notes et action items envoyés dans les 24h
```

**Récurrence :**
- **Hebdomadaire** — le [jour choisi, ex: mercredi]
- **Heure :** [ex: 9h30 – 10h30]
- **Rappel :** 15 min avant + 1 heure avant

**Participants :**
- Tous les membres de l'équipe (à ajouter)
- En option : manager / chef de projet

---

## 2. Modèle d'Email — Envoi de l'Ordre du Jour

```
Objet : 📋 Ordre du jour — Réunion Hebdo [Date]

Bonjour à tous,

Voici l'ordre du jour pour notre réunion hebdomadaire de demain [jour], 
à [heure] dans [lieu/lien visio].

📋 Ordre du jour :

1. Tour de table (5 min)
2. Revue des action items de la semaine dernière (10 min)
3. Avancement des projets (30 min)
   - Projet A : [responsable]
   - Projet B : [responsable]
4. Points bloquants (10 min)
5. Partage de bonnes pratiques : [nom] (5 min)
6. Planification de la semaine (10 min)
7. Bilan et clôture (5 min)

💡 N'hésitez pas à me faire parvenir vos points à ajouter avant [heure] 
pour que je les intègre à l'ordre du jour.

📎 Document de notes : [lien vers le document partagé]

À demain !

[Cordialement / L'animateur]
```

## 4. Outil de Suivi des Action Items

### Tableau de suivi (à créer dans Trello / Jira / Asana / Excel)

| ID | Action | Responsable | Date de création | Délai | Statut | Réunion liée |
|----|--------|------------|-----------------|-------|--------|-------------|
| 001 | ...    | ...        | 06/09/2026      | 13/09/2026 | En cours | Hebdo #1 |

### Statuts possibles :
- 🆕 **Nouveau** — vient d'être créé
- 🔄 **En cours** — en cours de traitement
- ✅ **Terminé** — complété
- 🚫 **Bloqué** — nécessite de l'aide
- ❌ **Annulé** — plus pertinent
- 📅 **Reporté** — déplacé à la semaine prochaine

## 5. Processus de Suivi Hebdomadaire

### Avant la réunion (24h avant)
1. ✅ L'animateur envoie l'ordre du jour par email.
2. ✅ Chaque membre ajoute ses points au document de notes.
3. ✅ Le secrétaire vérifie que le document est prêt.
4. ✅ Le lien visio / salle est confirmé.

### Pendant la réunion
1. ✅ Le secrétaire prend les notes dans le document partagé.
2. ✅ L'animateur gère le temps et recentre les discussions.
3. ✅ Les action items sont identifiés avec responsable et délai.

### Après la réunion (dans les 24h)
1. ✅ Le secrétaire finalise les notes et les envoie à toute l'équipe.
2. ✅ Les action items sont créés dans l'outil de suivi.
3. ✅ Le parking lot est archivé ou intégré au prochain ordre du jour.
4. ✅ Un feedback rapide est recueilli (optionnel).
