# Mise en route

Dans ce chapitre, vous allez installer Apollia OS, exécuter votre premier agent, et comprendre ce qui se passe réellement sous le capot.

À la fin de ce chapitre, vous aurez :

- un binaire `apollia-os` fonctionnel sur votre machine
- un premier agent Python qui répond à une tâche
- une compréhension claire des deux concepts centraux : le **manifest** et `run()`

Ce chapitre est délibérément minimal. L'objectif n'est pas d'explorer toutes les fonctionnalités — c'est de vous donner une base solide sur laquelle les chapitres suivants vont s'appuyer.

> **Durée estimée :** 30 à 45 minutes, compilation incluse.
