# Changelog — veille-ia

## [3.0.0] — 2026-05-07

### Refonte majeure (M5a release v0.1.0)

Application des **4 piliers obligatoires** issus de l'état de l'art agents IA 2025-2026 ([référence](../../docs/internal/research/agents-2026/)) et du skill [`apollia-agent-forge`](../../.claude/skills/apollia-agent-forge/SKILL.md).

### Added

- **Pilier 1 — Templates externalisés** :
  - `schemas.py` : Pydantic models (`Article`, `VeilleReport`, `Entity`, `EntitySignal`).
  - `templates/report.md.j2`, `templates/alert.md.j2`, `templates/summary.md.j2` (Jinja2).
  - Auto-repair sur `ValidationError` (max 3 retries).

- **Pilier 2 — Steps fonctionnels** : state machine 15 étapes (`state.py`).
  - Le LLM est appelé chirurgicalement sur 3 steps : EXTRACT_ENTITIES, SCORE_AND_RANK, exec_summary.
  - Les 12 autres steps sont déterministes Python.
  - Erreurs contextuelles par step + politique de recovery configurée.

- **Pilier 3 — Datasources externalisées YAML** :
  - `datasources/feeds.yaml` (15 feeds RSS/Atom).
  - `datasources/competitors.yaml` (12 concurrents directs + 6 indirects depuis cartographie).
  - `datasources/queries.yaml` (~30 requêtes par axe tech + competitive).
  - `datasources/scoring.yaml` (6 critères pondérés + critical_threshold).
  - Lecture priorité : `ctx.workspace` > local YAML > defaults.

- **Pilier 4 — Mémoire qualitative** :
  - Mémoire à entités : `entity:{type}:{id}` avec timeline `signals[]` et merge incrémental.
  - Dédup `seen:{hash}` confidence=1.0.
  - Mémoire procédurale : `procedure:daily-veille` apprise au premier run.
  - Bootstrap TTL 7j inchangé.

- **Nouveau worker** : `entity-extraction-worker` (skill A2A `extract-entities`).

- **Eval suite** :
  - `eval/cases.jsonl` (5 cas test).
  - `eval/run-eval.py` (script CLI N=5 runs).
  - `eval/golden/` (golden reports manuels de référence).

- **HITL conditionnel** : alerte critique automatique sur findings score ≥ threshold OR keyword match (`CRITICAL_KEYWORDS`).

- **Personnalisation `user.*`** : lecture `user.role`, `user.tech.stack`, `user.domain.sector`, `user.agents.hitl`. Adaptation du ton et de l'`executive_summary`.

- **`ctx.workspace`** : règles métier custom via sections APOLLIA.md (Feeds, Competitors, Queries, Scoring, Custom Rules).

- **Artefacts annexes complets** : `APOLLIA.md`, `setup.md`, `CHANGELOG.md`, `eval/`.

### Changed

- `synthesis-worker` ne produit plus du Markdown mais un JSON `VeilleReport` validable Pydantic. Le rendu Markdown est fait par le director via Jinja2.
- `veille-ia-agent` passe de ReAct loop pur à state machine explicite (15 steps).
- `agent.toml` : déclaration des 4 agents (au lieu de 3) + skills `input_schema` typés.
- Manifest étendu : `setup_notes`, `limitations`, `packages` (jinja2, pydantic, pyyaml).

### Removed

- `_INITIAL_SNAPSHOT` dict Python (datasources hardcodées) → externalisé en YAML.
- Markdown hardcodé dans `synthesis-worker.SYSTEM_PROMPT` → Jinja2 template externalisé.

### Anti-patterns corrigés

Cf. [09-anti-patterns.md](../../docs/internal/research/agents-2026/09-anti-patterns.md) :

- ✅ Lazy datasource hardcoding → YAML externalisé.
- ✅ Output template hardcoded → Jinja2 + Pydantic.
- ✅ Pas de lecture user.* → 4 clés lues en LOAD_USER_CONTEXT.
- ✅ Pas de lecture ctx.workspace → lecture des 5 sections.
- ✅ Pas de mémoire procédurale → `procedure:daily-veille`.
- ✅ Pas d'eval suite → `eval/` complet.
- ✅ Workers sans `input_schema` typé → `input_schema` ajouté pour les 3 skills.
- ✅ HITL theater (alerte sans contexte) → alert.md.j2 avec contexte enrichi.
